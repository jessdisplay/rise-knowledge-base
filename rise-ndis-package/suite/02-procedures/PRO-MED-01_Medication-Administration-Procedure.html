Purpose

This procedure sets out how, who and when for medication administration.

When this procedure starts

[The trigger, in one sentence a frontline worker recognises.]

Steps

# Who What they do Record / deadline
1 Service Manager Confirm the worker is assessed competent and the chart (FRM-MED-01) is current before any administration REG-HRM-02 check
2 Worker Check right person, medication, dose, route, time against the chart FRM-MED-01 signed each time
3 Worker Record administration immediately; record refusals and reasons FRM-MED-01
4 Worker Treat any error or near miss as an incident - report the same shift FRM-INC-01
5 Service Manager Review charts and errors on a set cycle Chart audit note

Escalation

If a step cannot be completed, or severity increases: escalate to the owner, then the CEO. Never leave a statutory deadline unowned.
