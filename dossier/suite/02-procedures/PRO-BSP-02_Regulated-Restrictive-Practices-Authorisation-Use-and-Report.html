Purpose

This procedure sets out how, who and when for regulated restrictive practices authorisation, use and reporting.

When this procedure starts

[The trigger, in one sentence a frontline worker recognises.]

Steps

# Who What they do Record / deadline
1 Service Manager Confirm any regulated restrictive practice is authorised and in a current behaviour support plan before use BSP + authorisation on file
2 Worker Use only as the plan describes: last resort, least restrictive, shortest time FRM-BSP-01 each use
3 Service Manager Record every use in REG-BSP-01 and report through the Commission's monthly online reporting Monthly report record ; per RPBS
4 Quality Manager Treat any unauthorised use as a reportable incident - PRO-INC-02 immediately REG-INC-01 + notification
5 Service Manager Feed usage data into BSP review with the practitioner Review note

Escalation

If a step cannot be completed, or severity increases: escalate to the owner, then the CEO. Never leave a statutory deadline unowned.
