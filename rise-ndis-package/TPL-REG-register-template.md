# [Register Title]

**Document type: Register.** The running log that proves a process operates over time.
*Worked example: REG-INC-01 Incident Register.*

> **How to use this template.** This document *specifies* the register; the register
> itself lives as a spreadsheet (or a system table) built to this specification. Auditors
> read registers before anything else: a current, complete register is the strongest
> single piece of evidence that a process is real. An empty register plus a perfect
> policy is a red flag, not a pass.

## 3. Column specification

[One row per column: name · type · allowed values · why it exists. Keep the register

| Column | Type / values | Why |
|---|---|---|
| Incident ID | auto number | Stable reference |

| Status | open / closed | Nothing left hanging |
